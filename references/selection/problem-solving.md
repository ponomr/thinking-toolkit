# Problem solving: Selection

Choose by the artifact required, then read the linked card.

| Model | Selection cue |
|---|---|
| [Ishikawa Diagram](../ishikawa-diagram.md) | A defined effect has multiple possible causes |
| [Five Whys](../five-whys.md) | One incident needs its causal chain traced to a process fix |
| [Fermi Estimation](../fermi-estimation.md) | A quantity must be estimated without direct data |
| [Red Teaming](../red-teaming.md) | A confident plan needs an independent adversarial challenge |
| [Abstraction Laddering](../abstraction-laddering.md) | The initial problem statement may be too narrow or vague |
| [Conflict Resolution Diagram](../conflict-resolution-diagram.md) | Opposing demands appear mutually exclusive |
| [Zwicky Box](../zwicky-box.md) | A solution can be assembled from independent dimensions |
| [Productive Thinking Model](../productive-thinking-model.md) | A defined problem needs a complete creative process |
| [Inversion](../inversion.md) | Failure modes or opposite conditions reveal the solution |
| [Issue Trees](../issue-trees.md) | A large problem needs non-overlapping decomposition |
| [After Action Review](../after-action-review.md) | A completed episode should become a lesson and a next action |
| [First Principles](../first-principles.md) | Conventions or analogies constrain solution quality |

## Distinctions

- One incident's causal chain to a process fix: Five Whys. Breadth of possible
  causes of a defined effect: Ishikawa. Full question-space decomposition: Issue Trees.
- Intended versus actual results of one completed episode, including success:
  After Action Review. Recurring patterns and structures across episodes:
  [Iceberg Model](../iceberg-model.md).
- Mutual causation and feedback: [Connection Circles](../connection-circles.md),
  rather than a strict tree. Semantic relationships:
  [Concept Map](../concept-map.md).
- Imagine failure conditions: Inversion. An independent challenger or responsive
  adversary attacking a plan: Red Teaming.
- Missing bounded quantity: Fermi Estimation. Option comparison with known
  criteria: [Decision Matrix](../decision-matrix.md).
