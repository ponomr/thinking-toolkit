# Connection Circles

**Category:** Systems thinking
**Also known as:** Causal connection circles, relationship circles

## Purpose

Turn a narrative about a system into a compact map of variables, directional
causal links, and closed feedback loops.

## Use When

- Several variables influence one another rather than forming one linear chain.
- A story contains repeated increases, decreases, delays, and reactions.
- The user needs to discover reinforcing or balancing loops.
- A group needs a shared causal hypothesis that can be tested and refined.

## Avoid When

- The goal is semantic understanding rather than causation; use Concept Map.
- The variables cannot be expressed as quantities that can rise or fall.
- The group has no evidence or plausible mechanism for directional links.
- A rigorous quantitative model is required for prediction.

## Inputs

- A bounded system, behavior-over-time question, and time horizon.
- A short narrative or evidence set describing changes in the system.
- Approximately five to ten important variables expressed as neutral nouns or
  noun phrases that can increase or decrease.
- Candidate causal mechanisms, delays, and confidence levels.

## Procedure

1. Draw a circle and place the selected variables around it.
2. Check each variable: it matters to the behavior, can vary, and is not written
   as an action or judgment.
3. For each plausible direct causal relation, draw an arrow from cause to effect.
4. Mark polarity:
   - plus: all else equal, an increase in the cause pushes the effect higher than
     it otherwise would be, and a decrease pushes it lower;
   - minus: all else equal, an increase in the cause pushes the effect lower than
     it otherwise would be, and a decrease pushes it higher.
5. Describe the mechanism for every arrow and mark material delays.
6. Distinguish evidence-supported links from hypotheses.
7. Find closed paths that return to the starting variable.
8. Classify each closed path as reinforcing or balancing and describe its
   behavior over time.
9. Identify leverage hypotheses, missing variables, and data needed to test the
   map.

## Guiding Questions

- Which variables change over time and matter to the outcome?
- Does this arrow represent direct influence or mere association?
- What is the mechanism, and on what timescale?
- What happens to the effect if the cause increases, all else equal?
- Where does a path close back on itself?
- Which loop dominates during the period of interest?
- What variable or delay might be missing?

## Output Format

- **System boundary and behavior:** one paragraph.
- **Variables:** five to ten defined quantities.
- **Links:** cause, polarity, effect, mechanism, delay, evidence, confidence.
- **Loops:** members, reinforcing or balancing type, behavior, confidence.
- **Leverage hypotheses:** proposed changes and possible unintended effects.

## Worked Example

A support organization maps unresolved tickets, response time, customer follow-up
messages, and agent workload. More unresolved tickets increase response time;
longer response time increases follow-up messages; more follow-ups increase
agent workload; higher workload increases unresolved tickets. The closed path is
reinforcing and explains escalation. A second loop adds staffing adjustments
that respond to backlog after a delay and is balancing. The map directs attention
to follow-up prevention and the staffing delay, not only individual productivity.

## Common Pitfalls

- Using events or actions instead of variables that can change.
- Drawing arrows for correlation without a causal mechanism.
- Confusing plus with "good" and minus with "bad."
- Omitting delays that explain oscillation or policy failure.
- Building an unreadable map with too many variables.
- Treating a qualitative map as a quantitative forecast.

## Useful Combinations

- **Reinforcing Feedback Loop** — analyze amplifying closed paths.
- **Balancing Feedback Loop** — analyze goal-seeking closed paths.
- **Iceberg Model** — connect loops to deeper structures and assumptions.
- **Second-Order Thinking** — explore consequences before a full map is needed.
