# Zwicky Box

**Category:** Problem solving
**Also known as:** Morphological box, morphological analysis

## Purpose

Generate novel whole-solution concepts by decomposing a complex design problem
into independent attributes and deliberately combining possible values across
those attributes.

## Use When

- A solution has several configurable dimensions.
- Familiar ideas dominate unstructured brainstorming.
- The goal is a broad option space or product concept exploration.
- A group can contribute diverse values for each attribute.

## Avoid When

- The problem or desired outcome is not yet defined.
- Attributes are strongly dependent and cannot be combined meaningfully.
- The need is to diagnose causes rather than design solutions.
- Safety or feasibility screening must occur before free combination.

## Inputs

- A precise design challenge, user, outcome, and constraints.
- A small set of logically distinct solution attributes.
- Several possible values for each attribute, including unconventional ones.
- Compatibility constraints and later evaluation criteria.

## Procedure

1. Define the problem and what a complete solution must accomplish.
2. Identify the attributes that jointly describe a whole solution. Prefer
   roughly three to seven attributes that are as independent as practical.
3. Create one column per attribute and generate several values for each. Defer
   judgment while expanding the value list.
4. Mark hard incompatibilities or non-negotiable constraints separately.
5. Create candidate concepts by selecting one value from each column. Use a mix
   of systematic, random, and intentionally surprising combinations.
6. Give every candidate a coherent one-sentence concept description.
7. Remove combinations that violate verified hard constraints, not merely
   convention or taste.
8. Cluster, refine, and evaluate the most promising concepts with a separate
   selection method.
9. Record unexplored regions of the box instead of claiming exhaustive review
   when the combination count is too large.

## Guiding Questions

- Which independent dimensions define a complete solution?
- Are any columns different names for the same underlying choice?
- What value would a non-expert or another industry propose?
- Which combinations feel strange but remain coherent?
- Which incompatibility is physical or ethical, and which is only conventional?
- What part of the space have we not sampled?
- What must be tested before evaluating the concept?

## Output Format

| Attribute A | Attribute B | Attribute C | Attribute D |
|---|---|---|---|
| Value | Value | Value | Value |

Then list candidate combinations with concept statement, novelty, hard-constraint
status, key uncertainty, and next evaluation step.

## Worked Example

A team redesigns customer research using five attributes: recruitment source,
interaction mode, timing, response format, and participant benefit. Combining
"in-product behavior trigger," "asynchronous interview," "after task failure,"
"voice note," and "early feature access" produces a concept the team had not
considered. It is refined into an opt-in recovery study and then evaluated for
privacy, feasibility, and learning value.

## Common Pitfalls

- Choosing attributes that overlap or omit a necessary part of the solution.
- Filling columns with minor variants rather than distinct values.
- Attempting to enumerate an enormous combination space mechanically.
- Filtering unusual combinations before understanding them.
- Mistaking generated concepts for validated solutions.
- Using the same criteria to generate and judge ideas simultaneously.

## Useful Combinations

- **First Principles** — derive attributes from essential functions and
  constraints.
- **Productive Thinking Model** — use the box during answer generation.
- **Decision Matrix** — compare refined concepts transparently.
- **Impact-Effort Matrix** — prioritize experiments for candidate combinations.
